============================================
Medidata.RWS.NET.Standard Documentation
============================================

Medidata.RWS.NET.Standard is a comprehensive, fluent .NET API library for `Medidata RAVE Web Services (RWS) <https://learn.mdsol.com/api/rws/getting-started-with-rave-web-services-95587258.html>`_. Modernized for .NET 8.0 and .NET 9.0, it handles boilerplate HTTP communication code, enabling faster integration with RWS APIs through a clean, async-first design.
